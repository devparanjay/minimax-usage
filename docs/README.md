# MiniMax Usage — Documentation

Welcome to the MiniMax Usage documentation. v0.1.0 is the current release.

MiniMax Usage is a VSCode extension that shows near-realtime usage of your MiniMax Token Plan and Credits in the VSCode status bar. It is for MiniMax subscribers who would rather check their 5-Hour Limit and Weekly Limit from the editor than switch to the platform console. A single click on the status bar entry opens a modal with the full breakdown, and a region picker covers both the overseas platform and the Mainland China platform.

The extension is distributed only through the VSCode Marketplace. To install it, follow the steps in the root [README's "Install" section](../README.md#install), then return here for setup, usage, and troubleshooting.

## What is in this directory

- [Installation](./installation.md) — install from the VSCode Marketplace, or sideload a `.vsix` for local testing.
- [Setup](./setup.md) — find the Subscription Key on the MiniMax platform, enter it in the extension, choose the region, choose the display mode.
- [Usage](./usage.md) — read the status bar entry and the usage modal, including every error state.
- [Troubleshooting](./troubleshooting.md) — common issues and the recovery path for each.
- [Security](./security.md) — where the Subscription Key is held, what the extension does and does not do, how to rotate the key, how to report a security issue.

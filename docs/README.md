# User Documentation

This directory contains the project's user-facing documentation —
everything a user of the extension needs to install, configure, and
use it.

## Layout

```
docs/
├── README.md               # this file
├── installation.md         # how to install from the VSCode Marketplace
├── setup.md                # finding the API key and entering it
├── usage.md                # how to read the usage modal
├── troubleshooting.md      # what to do when something doesn't work
└── security.md             # how the extension handles the API key
```

## Status

These documents are part of v0.1.0, phase 07
(`.kitchen/roadmaps/v0.1.0/phases/07-docs.md`). They will be
authored in that phase, after the user-facing strings from
phase 03 and the test report from phase 05 are available.

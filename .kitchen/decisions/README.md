# Decisions (ADRs)

Architectural and project decision records. Each ADR captures one
decision: its context, what was decided, and its consequences.

## Format

Numbered sequentially with the prefix `NNNN-<slug>.md` where `NNNN` is a
zero-padded sequence number. Statuses:

- **Proposed** — under discussion.
- **Accepted** — decision is in effect.
- **Superseded** — replaced by a later ADR (which links back here).
- **Deprecated** — no longer relevant.

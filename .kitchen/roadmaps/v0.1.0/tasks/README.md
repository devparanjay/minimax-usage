# v0.1.0 Tasks

Task-level tracking for v0.1.0. One file per phase, mirroring the
phase plan but at finer granularity.

## Files

- `01-discovery-tasks.md`
- `02-architecture-tasks.md`
- `03-design-tasks.md`
- `04-build-tasks.md`
- `05-test-tasks.md`
- `06-release-pipeline-tasks.md`
- `07-docs-tasks.md`

## Status legend

- `[ ]` — not started.
- `[~]` — in progress.
- `[x]` — completed.
- `[!]` — blocked (with a note about the blocker).

## Convention

Each task file is updated as work progresses. When a task moves,
the corresponding phase plan is updated too. Stale task files
are a smell — the team's job is to keep them current.
